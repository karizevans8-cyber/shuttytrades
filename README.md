# ShuttyTrades Demo v3.0

A complete mobile-first demo trading interface.

Included:
- Dashboard
- Forex markets/watchlist and search
- Interactive demo chart
- BUY/SELL order ticket
- Lot size, Stop Loss and Take Profit fields
- Open positions and close trade flow
- Portfolio
- Trade history
- Profile/settings
- Learning/KYC/Support/Settings demo actions
- Responsive desktop/tablet/mobile layout
- Mobile bottom navigation
- Demo balance of $10,000
- Real-money trading intentionally disabled

Important:
This is a frontend demo. It has no payment gateway, M-Pesa, bank/card connection, custody, broker/liquidity connection, live market execution, or real-money trading.

Run:
npm install
npm run dev

For static deployment:
npm run build
